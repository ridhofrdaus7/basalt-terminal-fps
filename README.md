Basalt Terminal is an original 4v4 3D tactical defusal FPS built in Three.js with no external runtime requests or build step. It features a two-bombsite three-lane terminal arena, first-to-5 round economy and Tactical Armory buy menu (`B`), recoil/spread/penetration/headshot gunplay across 5 weapons, volumetric smoke, flashbangs, frag grenades, Core Charge plant/defuse (`E`), positional Web Audio SFX, and 7 utility-aware tactical AI bots.

## Run it

```sh
node serve.ts
```

Then open http://127.0.0.1:8080 in a desktop browser with WebGL 2.
